# Announcing Logistix
We proudly announce the 0th preview version of Logistix package. Logistix is a constraint-based scheduler for tasks and fixed events using Google OR-Tools.

The package is maintained and created by Armin Sarkozi.

We recommend looking at our [documentation](../../full-docs.md) to get started.
